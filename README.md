# MiaoGram

An unofficial open-source Telegram client with enhanced features for everyday use.

## Features (Planned)

- ⚡ Multi-speed download (parallel chunk downloading)
- 👥 Unlimited multi-account support
- 📂 Enhanced folder management
- 🌐 Multi-engine translation
- 🎬 Immersive video player with gestures
- 🎨 Material 3 theming with dynamic colors
- 🔍 Enhanced channel discovery

## Building

### Prerequisites

- Android Studio Ladybug or later
- JDK 17
- Android SDK 34

### Setup

1. Clone this repository
2. Create `local.properties` with your API credentials:
   ```
   APP_ID=your_api_id
   APP_HASH=your_api_hash
   ```
3. Open in Android Studio and sync Gradle
4. Build and run

## API Credentials

You need your own Telegram API credentials to build this project.
Get them at https://my.telegram.org/apps

**Do NOT use someone else's API credentials.**
